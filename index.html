Guide d'installation

1. Jeux simples (.nwa)

Installer facilement les jeux sur sta calculatrice NumWorks.

  1. Choisir un jeu dans le catalogue.
  2. Cliquer sur son bouton de téléchargement pour récupérer le fichier .nwa.
  3. Connecter sa calculatrice à son ordinateur avec un câble USB ou à son téléphone avec un cable double USB-C ou un adaptateur.
  4. Ouvrir le site officiel : Transfert d'applications NumWorks . (La connection à un compte numworks est requise).
  5. Importer le ficher (.nwa) puis lancer le transfere.
  6. Une fois le transfert terminé, débrancher et lancer le jeu depuis la calculatrice.

2. Jeux complexes — Émulateur NES

Ces jeux nécessitent un émulateur et un fichier de données de jeu au format .nes.

Étape 1 — Installer l'émulateur

  1. Dans la catégorie « Jeux complexes », télécharger nofrendo.nwa.

Étape 2 — Télécharger un jeu NES

  1. Choisir un jeu dans la sous-catégorie « Jeux NES ».
  2. Télécharger le fichier correspondant au format .nes.
  3. Conserver ce fichier pour l'étape suivante.

Étape 3 — Charger le jeu

  1. Importer tout d'abord le fichier de l'émulateur (.nwa).
  2. Importer ensuite le fichier de données du jeu dans l'emplacement définit (.nes).
  3. Débrancher votre calculatrice et lancer le jeu une fois l'installation terminée.

Important : Veillez à bien avoir la derniere mise a jour avant de télécharger le jeu sur votre calculatrice. Sans cela, ça pourrait ne pas fonctionner.

Vérifie toujours la compatibilité des fichiers avec ta calculatrice NumWorks.
