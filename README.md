# 🎮 NumWorks Games — Catalogue de jeux

Bienvenue sur **NumWorks Games**, un catalogue communautaire regroupant des jeux et applications pour calculatrices NumWorks.

L'objectif est de réunir les fichiers nécessaires au même endroit, avec une interface simple, des téléchargements directs et un tutoriel d'installation.

## 🎮 Catégories

### 1. Jeux simples

Cette catégorie regroupe les applications qui s'installent directement sur la calculatrice grâce à leur fichier `.nwa`.

Chaque jeu possède une fiche avec sa description et un bouton de téléchargement.

### 2. Jeux complexes

Cette catégorie regroupe les jeux qui nécessitent plusieurs fichiers.

**Émulateur NES**
- `nofrendo.nwa` : l'émulateur NES pour NumWorks.

**Jeux NES**
- Fichiers `.nes` : jeux et données compatibles avec l'émulateur.

Le fonctionnement dépend de la compatibilité de chaque fichier avec l'émulateur et la version du système NumWorks utilisée.

## 📥 Téléchargements

Les fichiers téléchargeables sont regroupés dans le dossier `files/`.

Pour ajouter un jeu :
1. Place le fichier correspondant dans `files/`.
2. Ajoute sa fiche dans `index.html`.
3. Vérifie que le lien de téléchargement correspond exactement au nom du fichier.
4. Teste le téléchargement depuis le site publié.

## 📘 Tutoriel

Un tutoriel d'installation sera ajouté prochainement pour expliquer comment transférer les applications et utiliser les fichiers nécessaires.

## 🌐 Hébergement

Le catalogue est conçu pour être hébergé gratuitement avec **GitHub Pages**.

Une fois le site publié, son adresse pourra être partagée avec un QR code afin de permettre à d'autres utilisateurs d'accéder facilement au catalogue.

## ⚖️ Crédits et droits d'utilisation

Ce projet est un catalogue communautaire indépendant. Il n'est pas affilié officiellement à NumWorks.

Les applications, émulateurs et fichiers de jeux peuvent appartenir à des auteurs différents. Consultez leurs dépôts d'origine et leurs licences respectives avant de les redistribuer.

Ne publiez que les fichiers que vous êtes autorisé à partager.
